## 📖 Overview
<a id="overview"></a>

**Gerbv** is a powerful and free tool designed for viewing, printing, and converting Gerber (RS-274X) files, which are essential in the production of printed circuit boards (PCBs). With the latest version of Gerbv, users can efficiently analyze and validate their designs with full functionality.

This user-friendly software allows you to open multiple circuit designs simultaneously, facilitating easy measurements and comparisons between different models. Whether you need to print your designs or export them in formats like PNG, PS, SVG, or PDF, Gerbv has all the features you need to streamline your workflow.

## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **View Multiple Designs** — Open several circuit designs layered for easy comparison and measurement.
- **Export Options** — Export your designs in various formats including PNG, PS, SVG, and PDF.
- **User-Friendly Interface** — Simple layout with controls at the top and layer management on the left.
- **Flexible Measurement Units** — Easily switch between centimeters, millimeters, and inches with a click.

### Advanced Features:
- **Print Capability** — Print Gerber files directly from the application.
- **Layer Management** — Efficiently manage and view layers for enhanced analysis.
